# 顺路 · 校园跑腿互助平台

> 顺路帮个忙，校园更近一点。

把散落在微信群、朋友圈里的跑腿需求集中起来，让同校同学可以：
**发布任务 → 同学接单 → 完成跑腿 → 双方评价 → 积累校园信用。**

**在线访问：https://yichenacademic.github.io/campus-errand/**

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/，可直接静态部署
```

桌面端打开时，左侧有「演示路线」，可以一键跳到每个关键步骤；手机端打开直接是 H5 页面。

## 部署

- 托管在 GitHub Pages，由 `.github/workflows/deploy.yml` 自动构建发布：**推送到 `main` 分支即更新线上版本，访问地址保持不变**。
- 使用 hash 路由（如 `/#/task/t01`），刷新和直接打开二级页面都不会 404；`public/404.html` 会把 `/campus-errand/task/t01` 这类路径自动转到对应页面。

## 页面结构

| 页面 | 路由 | 说明 |
| --- | --- | --- |
| 任务广场 | `/` | 实时待接单任务、类型筛选、搜索、排序（最新 / 快截止 / 奖励高） |
| 发布任务 | `/publish` | 三步：选择类型 → 填写信息（含推荐奖励）→ 预览并确认发布 |
| 任务详情 | `/task/:id` | 状态进度、路线、奖励、截止时间、发布者信用、私密信息、互评、进度记录；按角色展示操作 |
| 我的任务 | `/my-tasks` | 进行中 / 我发布的 / 我接的 / 已完成，待我处理的排最前 |
| 个人主页 | `/me` | 校园信用分、信用等级与权益、收到的评价、信用记录与规则 |

## 任务状态机

```
open 待接单 ─接单─▶ accepted 已接单 ─开始任务─▶ started 进行中 ─已取到─▶ picked 已取到 ─已送达─▶ delivered 已送达 ─▶ completed 已完成 ─▶ 双方互评
   │                                                                                            （跑腿者「完成任务」或发布者「确认收到」）
   └─发布者取消（仅限无人接单时）─▶ cancelled 已取消                     open 且超过截止时间 ⇒ 派生为「已过期」
```

- 所有流转集中在 `src/store/logic.ts` 的纯函数 `reduce` 中，每一步都校验**角色 + 当前状态**：不能接自己的任务、已被接单的任务不能再接、不能跳步、不能重复完成或评价，非法操作返回中文提示。
- 每次状态变化都有明确提示：「任务已开始」「已更新为：已取到物品」「已更新为：已送达」「任务已完成」。
- 单人演示时没有真实的「另一位同学」，详情页提供明确标注的「演示模式」按钮来模拟对方的操作（接单、推进进度、评价）。

## 数据一致性

- 首页、详情页、我的任务都读取同一份 `state.tasks`，只是筛选维度不同，不存在各自缓存的副本。
- 状态保存在 `localStorage`，刷新不丢失；同时打开多个标签页时，通过 `storage` 事件实时同步。
- 演示任务的时间相对「现在」生成，闲置 6 小时后只刷新广场上他人的任务，**我发布的、我接的、信用记录都会保留**；旧版本数据会自动迁移。

## 信任设计

- **实名但不暴露**：学生认证后对外只显示「林同学」，不显示全名。
- **私密信息分级**：取件码、门牌号只有接单后才可见，广场上的路人看不到。
- **信用分闭环**：按时完成 +1、五星好评 +1、超时送达 -2；信用等级决定能接哪些任务。
- **社区规范**：发布页明确提示不得发布代课、代考、代签到等任务。

## 技术说明

- React 18 + TypeScript + Vite，路由用 `react-router-dom`（HashRouter，方便静态部署），图标用 `lucide-react`。
- 无后端：状态用 Context 管理，持久化到 `localStorage`，可在「我的」页手动重置演示数据。
- 样式为手写 CSS + 设计令牌（`src/styles.css` 顶部），主色「校园青」，奖励用暖橙点缀。

```
src/
├── data/        # 任务类型、校园地点（含耗时估算）、Mock 用户与任务
├── store/       # logic.ts 状态机纯函数；AppStore.tsx 状态容器、持久化、提示
├── components/  # 任务卡片、布局与导航、评价面板、基础 UI
└── pages/       # 五个核心页面
```
